# How to compare mobile bar companies

Quotes only compare fairly when each company is pricing the same thing. Write down your event first, then ask each company to answer the same eight questions. The worksheet below does that, and leaves the decision with you.

## The worksheet

| Question | Company A | Company B | Company C |
|---|---|---|---|
| **Service:** staff only, staff and equipment, or full package? | | | |
| **Team:** how many people, what experience, who supervises? | | | |
| **Menu:** fixed list, or tailored? Alcohol-free options included? | | | |
| **Supplies:** who provides alcohol, ingredients, ice, glassware? | | | |
| **Setup:** space, access, power and water the company needs from you | | | |
| **Travel and delivery:** included or extra? | | | |
| **Total cost:** hours, equipment, ingredients, travel, VAT, minimum spend | | | |
| **Confirmation:** when is it confirmed, who tells you, what are the cancellation and replacement terms? | | | |

## Quote, deposit and confirmed booking are different stages

Platforms and companies handle these differently. Some show an instant quote, some ask you to wait for a supplier to confirm, some take a deposit first. Note which stage you are at before you assume the date is secure.

## Evidence to look for

Real photographs of the company's own events, reviews you can trace to a platform, and a clear description of who will actually attend. Treat unattributed claims such as "the best in the area" as marketing.
