# What do I need to provide when I hire a bartender?

It depends on the package. Suppliers publish different inclusions: some supply only the person, some add ingredients, equipment or a bar. Use the checklist below and mark each line as "me", "bartender" or "agreed with the supplier" before you confirm.

## Responsibility checklist

| Item | Me | Bartender or supplier | Agreed |
|---|---|---|---|
| Alcohol | | | |
| Mixers, juices, garnishes and other ingredients | | | |
| Ice, including ice for chilling | | | |
| Bar tools (shakers, jiggers, strainers) | | | |
| Glassware, and collecting it afterwards | | | |
| A counter or bar, and fridge space | | | |
| Water, and a place to wash up | | | |
| Power, if the supplier specifies any | | | |
| Alcohol-free options | | | |
| Setup time before guests arrive | | | |
| Clearing and rubbish at the end | | | |
| Parking and access for the bartender | | | |

## Questions that avoid surprises

- If I supply the drinks, who decides quantities? See [supplying your own alcohol](/stories/supply-own-alcohol-hire-bartender).
- Is setup time part of the paid hours?
- What happens to leftovers?
