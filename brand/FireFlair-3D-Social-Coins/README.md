# FireFlair 3D social coins

The four GLBs use the enlarged Inter Black Italic FF outlines from the social coin. Each has a continuous metallic rim, matte Ink face, Oxblood inset and bevelled FF letters. The same mark reads upright on both faces as the coin turns.

| Dimension at exported scale | Value |
| --- | --- |
| Diameter | 40 mm |
| Rim thickness | 2.52 mm |
| Letter relief above each face | 0.70 mm |
| Total depth across the highest letter faces | 3.32 mm |

| Finish | Model |
| --- | --- |
| Bronze | `models/ff-social-bronze.glb` |
| Silver | `models/ff-social-silver.glb` |
| Gold | `models/ff-social-gold.glb` |
| Platinum | `models/ff-social-platinum.glb` |

The models use self-contained glTF 2.0 geometry and materials. Each contains the coin body and four separate raised letters, two on each face. The comparison PNG uses the same camera angle for the four finishes. The MP4 shows one full rotation of the gold model.

The published FireFlair prototype release `1794321498-9368` uses separate CSS front and back faces with stacked edge layers. The continuous rim and raised geometry in this set provide the equivalent physical form in a 3D renderer. [FireFlair prototype](https://claude.ai/artifact/BHgRj4ZH1mWdMtf8heW82s)
