# Directory agent changelog

One line per run of the directory agent, newest at the bottom, in the form:

`YYYY-MM-DD · added N · updated N · proposed N · <slugs of the companies touched>`

"Added" counts new cards, sections and questions. "Updated" counts items the agent changed or removed because the website changed (only items it wrote itself). "Proposed" counts cards marked `proposed: true` beside something a person edited. See `AGENT.md`.
