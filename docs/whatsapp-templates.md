# WhatsApp reply wording

| Booking type | Buttons | Meaning |
|---|---|---|
| Exclusive shift | Accept shift / Unavailable / Ask | Accept shift confirms the shift. |
| Autofill | I'm available / Unavailable / Ask | I'm available does not confirm the shift; the booker picks. |

The same words are used on the website. Templates need provider approval; Core owns the reply handling.
