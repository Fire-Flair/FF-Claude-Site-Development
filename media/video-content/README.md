# FireFlair video content

Working files for FireFlair video and Instagram Reels.

## ff-team-reel/references

Cropped reference images supplied for the FF Team reel (bears in the bar).
They are fed to the video model as character and set references.

- `king_host.png` - the King (fedora, pinstripe suit), host on the guest side of the bar
- `crown_bartender.png` - crowned bartender bear with shaker
- `doors_artwork.png` - clubhouse doors artwork. Shows the old spade emblem: reference for the door design only. New work uses the round FF medallion.
- `dress_reference.png` - wardrobe reference for guests in evening dresses
